Character Lookup

Independent character-data tools for DC Universe Online players. Every search pulls live data straight from Daybreak's public Census API — nothing is cached or stored by ToonData.

🔒 Search using a public character name only. ToonData will never ask for your Daybreak, PlayStation, Xbox, Nintendo, Steam, or other gaming-account password.
ℹ️ Character information is retrieved live from Daybreak's public Census API and may be delayed, incomplete, or inaccurate. ToonData is unable to update or correct information maintained by Daybreak.

Using the shared public test key s:example, which Daybreak rate-limits to 10 requests per minute per IP. A single lookup can use several requests depending on how many feats the character has, so back-to-back searches may briefly hit that limit — if you see a rate-limit message, just wait about a minute.
