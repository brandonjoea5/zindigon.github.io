DCUO Character Lookup

Live data from the official Daybreak Census API (dcuo:v1) — no data is stored anywhere, every search hits the API fresh.

Using the shared public test key s:example, which Daybreak rate-limits to 10 requests per minute per IP. A single lookup can use 4–10+ requests depending on how many feats the character has, so back-to-back searches may briefly hit that limit — if you see a rate-limit message, just wait about a minute. Before sharing this page with anyone else, request your own service ID at census.daybreakgames.com and swap it into the SERVICE_ID constant near the top of this file's script.
